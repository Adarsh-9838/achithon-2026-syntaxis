## Domain

DevSecOps / Generative AI / Agentic Systems



## Problem Statement

Large open-source and enterprise software repositories frequently contain complex dependency trees, interconnected modules, and distributed services. As these codebases evolve, they can accumulate outdated or vulnerable dependencies, insecure coding patterns, and subtle logic flaws that are difficult to identify through manual review alone.

Traditional static application security testing (SAST) tools and dependency scanners can detect many predefined vulnerabilities and known package weaknesses. However, their findings may remain fragmented across tools, while vulnerabilities involving complex data flows, cross-function interactions, or service boundaries may require additional contextual analysis to determine their relevance and potential impact.

The proposed project aims to develop an Automated Multi-Agent Codebase Vulnerability and Dependency Graph Auditor that analyzes Git repositories using a coordinated team of specialized AI agents.

The system will parse supported source files into abstract syntax trees (ASTs), construct a graph of code relationships and direct and transitive dependencies, perform targeted data-flow and taint analysis, and correlate dependency versions with known vulnerability advisories. A central orchestration framework will coordinate the agents, consolidate their findings, and maintain evidence linking each reported issue to relevant code locations, dependency paths, or advisory records.

For findings supported by sufficient evidence, the system will recommend remediation strategies and optionally generate focused code or dependency patches. Proposed changes will be evaluated through unit tests, targeted security tests, static analysis, and regression checks before being presented as reviewable patch files or draft pull requests.

The system will distinguish confirmed findings from suspected vulnerabilities and will not treat AI-generated explanations, agent consensus, or passing tests as definitive proof of security. Its primary objective is to improve vulnerability discovery, cross-component analysis, remediation efficiency, and the explainability of automated security reviews.

## Key Deliverable

A functional command-line auditing tool that ingests a GitHub repository or local codebase, analyzes supported source files and dependency manifests, constructs a code and dependency graph, and produces prioritized, evidence-linked vulnerability findings.

The system will identify known dependency vulnerabilities, analyze selected source-to-sink data-flow pathways, coordinate specialized AI agents, and recommend remediation strategies. For suitable findings, it will generate patches and evaluate them against relevant tests and security checks.

The primary output will be a structured audit report containing vulnerability descriptions, affected files and dependencies, supporting code paths, advisory references, remediation recommendations, and patch-validation results. Optional functionality will generate reviewable patch files or draft pull requests without automatically merging changes into protected branches.

### Expected Outcome

The project will demonstrate how graph-based code analysis, vulnerability intelligence, targeted static analysis, and multi-agent AI orchestration can be combined into an explainable security auditing workflow.

Its effectiveness will be evaluated using labeled vulnerable and safe examples, dependency advisory matching accuracy, source-to-sink path accuracy, false-positive rates, patch test success rates, regression testing, and analysis performance.
