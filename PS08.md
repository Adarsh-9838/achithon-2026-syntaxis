## Domain

AI Security / Cybersecurity / Information-Flow Control


## Problem Statement

AI agents increasingly interact with tools to read documents, generate reports, save information, and deliver content to users or external systems. However, untrusted documents may contain instructions designed to manipulate agent behavior, override trusted policies, or disclose confidential information. If an agent relies on its own interpretation of these instructions to determine whether an action is permitted, it may perform operations that violate established security requirements.

Existing prompt-level safeguards cannot independently guarantee that every proposed action complies with authorization rules, particularly when instructions are embedded in documents or when workflows span multiple execution sessions. Security restrictions may also be lost when information is summarized, transformed, saved, or reloaded unless the system explicitly preserves its sensitivity and provenance metadata.

The proposed project aims to develop AGENTGATE, a security gateway that enforces trusted authorization policies and information-flow restrictions before AI-proposed actions are executed.

The system will separate trusted security policies from untrusted document content and AI-generated action proposals. Every proposed tool operation will be evaluated against explicit permissions covering the requesting identity, requested operation, target resource, recipient authorization, and sensitivity of the information involved. Unauthorized actions will be blocked before execution, regardless of whether the AI considers the action appropriate.

AGENTGATE will also maintain persistent security labels and provenance metadata across derived reports and resumed workflows. Summarization, storage, and reloading will not automatically remove existing restrictions, and only an explicitly authorized process will be permitted to change a protected classification.

The final prototype will provide three local tools for document reading, report saving, and delivery to a mock inbox. A Streamlit dashboard will demonstrate successful authorized operations, blocked unauthorized deliveries, persistent restrictions after workflow resumption, and an auditable explanation for every authorization decision.

An automated test suite will evaluate authorization correctness, information-flow enforcement, prompt-injection resistance, persistence, and audit completeness. An optional LLM integration may interpret user requests and propose tool actions, but the independent policy gateway will retain exclusive authority over authorization decisions.

## Key Deliverable

A functional local demonstration featuring three protected tools: document reading, report saving, and mock inbox delivery.

The system will enforce trusted permissions before executing any protected action, prevent unauthorized delivery of restricted information, and preserve security restrictions when information is summarized, saved, or reloaded.

The application will demonstrate authorized tasks succeeding, unauthorized deliveries being blocked, restrictions surviving workflow resumption, and an audit trail explaining each decision. Automated tests will verify that blocked actions never reach the underlying tool and that security labels remain effective across workflow boundaries.

Any prerecorded action replay will be clearly labeled as a replay or simulation rather than a live execution.

### Expected Outcome

AGENTGATE will demonstrate how an independent policy-enforcement layer can reduce the risk of unauthorized actions in tool-using AI systems.

Its effectiveness will be evaluated through authorization accuracy, prevention of unauthorized tool execution, persistent information-flow enforcement, correct behavior after workflow resumption, and the completeness and accuracy of audit records.
