## Domain

## Problem Statement

Researchers and data engineering teams frequently encounter situations where an analytical result changes unexpectedly after modifications to input data, preprocessing logic, configuration parameters, dependencies, or execution environments. In multi-stage pipelines, these changes can propagate through subsequent transformations and alter final metrics, reports, or scientific conclusions.

Comparing only the final outputs may reveal that a discrepancy exists, but it often fails to identify the stage where the difference originated. Furthermore, exact comparisons can incorrectly flag harmless numerical variation, while insufficient execution history can make it difficult to reproduce earlier results or verify a suspected explanation.

The proposed project aims to develop REPROTRACE, a pipeline observability and reproducibility tool that records intermediate artifacts and execution metadata, compares pipeline runs, and identifies the earliest meaningful divergence between them.

The system will instrument an explicitly defined five- or six-stage Python pipeline and record stage inputs, outputs, configuration parameters, artifact fingerprints, schemas, and relevant execution metadata. Using Python, pandas, and NumPy, it will compare runs at the structural, data, configuration, and numerical levels, applying declared absolute and relative tolerances to distinguish meaningful differences from acceptable numerical variation.

The tool will provide a Streamlit dashboard displaying execution history, stage-level comparisons, observed differences, and evidence-based hypotheses about potential causes. It will also support controlled reruns that revert a selected configuration or code change while holding other relevant conditions constant, where feasible, to test whether the original result can be restored.

An exportable investigation report will document the compared runs, earliest observed divergence, supporting artifact differences, suspected explanation, and controlled rerun outcome. The system will distinguish observed evidence from inferred causes and will explicitly report unresolved investigations when the available evidence is insufficient.

The final objective is to deliver a functional tool that helps researchers and data teams diagnose unexpected analytical changes, improve reproducibility, and reduce the time required to investigate pipeline regressions.

## Key Deliverable

A functional dashboard for an explicitly instrumented five- or six-stage Python pipeline that records intermediate artifacts and compares different executions.

The application will display execution history, stage-level differences, the earliest meaningful divergence, and relevant metadata such as row counts, schemas, configuration values, and numerical deviations. Comparisons will use declared tolerances appropriate to the data being evaluated.

The system will include a controlled rerun feature that reverts a selected change and tests whether the original intermediate outputs and final analytical result are restored. It will also generate an exportable investigation report containing run identifiers, supporting evidence, suspected causes, and rerun outcomes.

### Expected Outcome

REPROTRACE will demonstrate how pipeline instrumentation, artifact comparison, numerical tolerance handling, and controlled reruns can improve the explainability and reproducibility of analytical workflows.

Its effectiveness will be evaluated using earliest-divergence detection accuracy, numerical comparison correctness, duplicate-record detection, controlled rerun reproducibility, report completeness, and instrumentation overhead.
