## Problem Statement

Deleting a user's records from a database does not automatically remove their contributions from downstream artifacts such as engineered features, cached predictions, and trained machine learning models. Without explicit data lineage and coordinated deletion procedures, organizations may be unable to determine which artifacts are affected by a deletion request or verify whether the required updates have been completed.

The proposed project aims to develop FORGETGRAPH, a dependency-aware deletion orchestrator that tracks the flow of user-associated data through a controlled machine learning pipeline and coordinates its removal from source records and derived artifacts.

The system will represent source data, engineered feature datasets, prediction caches, and a Ridge regression model as nodes in an artifact dependency graph. When a deletion request is received, the orchestrator will identify affected artifacts and execute the required operations in dependency order, including source-record removal, feature recomputation, cache invalidation, and model replacement.

To verify the model update, FORGETGRAPH will retrain the replacement Ridge regression model using the retained dataset and fixed preprocessing and training settings. It will independently retrain a reference model under the same conditions and compare their coefficients, intercepts, and predictions using explicitly declared numerical tolerances. Verification results will be recorded separately from execution status so that incomplete or unsuccessful deletion operations are not incorrectly reported as successful.

The system will also maintain a persistent deletion registry to handle repeated requests safely and prevent previously deleted identifiers from re-entering through the managed ingestion path. A Streamlit dashboard will display the artifact dependency graph, deletion progress, source and feature removal, cache invalidation, model replacement, and verification evidence.

The final objective is to deliver a functional and testable system that demonstrates dependency-aware deletion, reproducible model replacement, independent verification, and safe handling of repeated deletion requests.

## Key Deliverable

A working dashboard that demonstrates deletion across a controlled pipeline containing source data, derived features, cached predictions, and one Ridge regression model.

The application will visualize the artifact dependency graph, identify affected artifacts, execute the required deletion and update operations, and report the status of each step. It will independently retrain a reference model on the retained dataset using fixed preprocessing and training settings, then compare the replacement model against the reference using explicit numerical tolerances.

The prototype will also demonstrate safe handling of repeated deletion requests, prevention of deleted identifiers from returning through the managed ingestion path, and an auditable record of execution and verification outcomes.

### Expected Outcome

FORGETGRAPH will demonstrate how data lineage, dependency-aware orchestration, model retraining, and independent numerical verification can improve the reliability of deletion workflows in machine learning systems.

Its effectiveness will be evaluated through artifact-identification accuracy, deletion completeness, numerical agreement with independent retraining, repeated-request safety, re-ingestion prevention, and recovery from simulated failures.
